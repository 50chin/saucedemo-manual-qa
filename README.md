# Проект по ручному тестированию SauceDemo

## О проекте

Учебный проект по функциональному ручному тестированию демонстрационного интернет-магазина SauceDemo

## Область тестирования

- Авторизация
- Каталог товаров
- Сортировка
- Корзина покупок
- Оформление заказа
- Навигация и боковое меню

## Использованные подходы

- Функциональное тестирование
- Позитивные и негативные сценарии
- Составление чек-листов
- Разработка тест-кейсов
- Выполнение тест-кейсов
- Подготовка отчётов о результатах тестирования
- Документирование обнаруженных дефектов

## Результаты тестирования

- Выполнено 40 тест-кейсов
- Успешно пройдено: 40
- Не пройдено: 0
- Дефектов не обнаружено в рамках выполненных сценариев

## Тестовая среда

- Операционная система: macOS
- Браузер: Google Chrome
- Версия браузера: не зафиксирована

## Артефакты проекта

- План тестирования
- Чек-лист
- Тест-кейсы
- Итоговый отчёт о тестировании
- Отчёты о дефектах

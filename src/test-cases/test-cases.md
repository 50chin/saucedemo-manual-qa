## Authentication — авторизация


| ID          | Сценарий и шаги                                                  | Ожидаемый результат                                                               |
| ----------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| TC-AUTH-001 | Открыть страницу авторизации                        | Отображаются поля логина и пароля, кнопка входа             |
| TC-AUTH-002 | Ввести `standard_user` `secret_sauce`, нажать Login               | Пользователь попадает в каталог товаров                          |
| TC-AUTH-003 | Ввести корректный логин и неверный пароль | Вход не выполняется, отображается сообщение об ошибке |
| TC-AUTH-004 | Ввести несуществующий логин и пароль          | Вход не выполняется, отображается сообщение об ошибке |
| TC-AUTH-005 | Оставить оба поля пустыми и нажать Login          | Вход не выполняется, показана валидация                           |
| TC-AUTH-006 | Заполнить логин,оставить пароль пустым      | Вход не выполняется, показана валидация                           |
| TC-AUTH-007 | Оставить логин пустым, заполнить пароль     | Вход не выполняется, показана валидация                           |
| TC-AUTH-008 | Войти и выбрать Logout в меню                               | Пользователь возвращается на страницу авторизации       |
